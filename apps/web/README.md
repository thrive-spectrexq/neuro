# @neuro/web

Web portal and cloud viewer for Neuro built with React 18, Vite, and TypeScript.

## Features

- Full vault viewer and editor with live markdown preview
- Interactive Knowledge Graph visualization
- AI Agent chat interface with citation inspection
- Settings and privacy center (Data export, account deletion)

## Development

```bash
# Start Vite development server
pnpm dev

# Typecheck & Unit Tests (Vitest)
pnpm typecheck
pnpm test

# Build production bundle
pnpm build
```
